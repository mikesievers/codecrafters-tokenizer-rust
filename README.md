This is a Rust implemtation of the ["Build Your Own Tokenizer" Challenge](https://codecrafters.io/challenges/tokenizer).

WORK IN PROGRESS

- Byte-par encoding tokenizer that
  - trains a vocabulary
  - encodes text
  - decodes token IDs

The goal is to learn GPT-2's encoding.
